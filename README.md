# 조선 유람 (Joseon Tour)

실무 수준의 보드게임 프로젝트로 리팩토링된 보드 게임입니다.

## 프로젝트 구조

```
src/
  ├── app.py              # 메인 애플리케이션 (게임 루프)
  ├── game/               # 게임 로직 (비즈니스 로직)
  │   ├── manager.py      # 게임 상태 관리
  │   ├── player.py       # 플레이어 모델
  │   └── tile.py         # 타일 모델
  ├── ui/                 # UI/렌더링 계층
  │   ├── renderer.py     # 메인 렌더러
  │   ├── board_ui.py     # 보드판 렌더링
  │   ├── hud.py          # 콘솔·버튼·정보 표시
  │   ├── dice_ui.py      # 주사위 애니메이션
  │   └── ui_state.py     # UI 상태 관리
  └── core/               # 공통 유틸리티
      ├── constants.py    # 색상, 경로 상수
      ├── resource_loader.py  # 안전한 리소스 로더
      └── types.py        # 타입 정의

config/
  └── settings.py         # 게임 설정 (FPS, 초기금액 등)

assets/
  ├── images/             # 모든 이미지 파일
  └── fonts/              # 폰트 파일

tests/                     # 테스트 코드
```

## 설치 및 실행

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 게임 실행
```bash
python main.py
```

## 게임 규칙

- **4명의 플레이어**: Red, Blue, Green, Yellow
- **초기 자금**: 5,000원
- **보드 크기**: 20개 타일

### 타일 종류

| 타일 | 위치 | 설명 |
|------|------|------|
| 출도 (Go) | 0번 | 통과 시 2,000원 획득 |
| 일반 땅 | 1,2,3,4,6,7,8,9,11,12,13,14,16,17,18,19 | 구매 가능, 통행료 지불 |
| 미정 | 5번 | 소유한 땅 1개 업그레이드 |
| 무주도 (Jail) | 10번 | 2턴 이동 불가 (더블 시 탈출) |
| 학 | 15번 | 원하는 타일로 순간이동 |

### 게임 플레이

1. **스페이스바**: 주사위 굴리기
2. **더블**: 500원 보너스 + 재굴림
3. **타일 도착**: 자동 구매/업그레이드/통행료 처리
4. **건물 매각**: 통행료 못 낼 시 자동 매각
5. **우승 조건**: 
   - 다른 플레이어가 모두 파산
   - 건물 개수 5개 이상 차이

## 리팩토링 내용

### 구조 개선
- ✅ **UI/Logic 분리**: `game/`은 순수 로직만, `ui/`는 렌더링만 담당
- ✅ **전역 변수 제거**: `UIState` 클래스로 UI 상태 캡슐화
- ✅ **안전한 리소스 로더**: 이미지/폰트 로드 실패 시 placeholder 반환
- ✅ **타입 안정성**: 게임 이벤트 타입 정의 (`TileEventType`)
- ✅ **중앙화된 설정**: 모든 게임 설정을 `config/settings.py`에서 관리

### 코드 품질
- 예외 처리: 모든 리소스 로드에 try/except 적용
- 캐싱: 한 번 로드한 이미지/폰트는 재사용
- 문서화: 각 클래스·함수에 docstring 추가
- 타입 힌트: 함수 인자·반환값에 타입 명시

## 키 조합

| 키 | 기능 |
|----|------|
| SPACE | 주사위 굴리기 |
| F1 + P | 모든 플레이어 위치 출력 (디버그) |
| F1 + M | 모든 플레이어 돈 출력 (디버그) |
